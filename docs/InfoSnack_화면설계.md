>
> **v1.1-v1.4 변경점 요약**: 수집처 자동 감지/미리보기, 수집처 상세/편집, 관리자 대시보드, 인증/i18n/팀 관리, PRD/API/화면설계 동기화 원칙을 반영.

## 1. 디자인 원칙

### 1.1 핵심 원칙

| 원칙 | 설명 |
|------|------|
| 스캔 가능성 | 카드 기반 UI로 많은 콘텐츠를 빠르게 훑을 수 있어야 함 |
| 최소 클릭 | 주요 기능은 2클릭 이내 도달 |
| 맥락 유지 | 콘텐츠를 보면서 챗봇 질의 가능 |
| 일관성 | 동일한 컴포넌트, 동일한 인터랙션 |
| 접근성 | 다크/라이트 모드, 키보드 네비게이션 |

## 4. 상세 화면 설계

### 4.0 인증 - 로그인/회원가입 (A-01, A-02)

**목적:** 초대받은 사용자가 FastAPI-owned auth로 로그인하거나 초대 토큰으로 가입

**로그인 (A-01)**

```
┌───────────────────────────────────────────────┐
│ 🍪 InfoSnack                                  │
│                                               │
│ 이메일                                        │
│ ┌─────────────────────────────────────────┐  │
│ │ user@company.com                        │  │
│ └─────────────────────────────────────────┘  │
│ 비밀번호                                     │
│ ┌─────────────────────────────────────────┐  │
│ │ •••••••••••                             │  │
│ └─────────────────────────────────────────┘  │
│                                               │
│                         [로그인]             │
│ 초대를 받았나요? [초대 링크로 가입]           │
└───────────────────────────────────────────────┘
```

**회원가입 (A-02, 초대 기반)**

```
┌───────────────────────────────────────────────┐
│ 🍪 InfoSnack                                  │
│                                               │
│ 초대받은 팀: AI Agent Team                    │
│ 이메일: user@company.com                      │
│                                               │
│ 이름                                          │
│ ┌─────────────────────────────────────────┐  │
│ │ 홍길동                                  │  │
│ └─────────────────────────────────────────┘  │
│ 비밀번호 설정                                │
│ ┌─────────────────────────────────────────┐  │
│ │ •••••••••••                             │  │
│ └─────────────────────────────────────────┘  │
│ 언어 [한국어 ▼]                              │
│                                               │
│                         [가입 완료]          │
└───────────────────────────────────────────────┘
```

- 초대 토큰이 없거나 만료되면 로그인 화면으로 돌려보내고 관리자에게 재초대 요청 안내를 표시한다.
- 가입 완료 후 기본 언어는 S-01 프로필 설정에서 다시 변경할 수 있다.
- 로그인 성공 시 backend가 `infosnack_at`, `infosnack_rt`, `infosnack_csrf` cookie를 발급한다.
- 상태 변경 요청은 `X-CSRF-Token` header를 포함한다. CSRF 실패, lockout, invitation 만료는 화면에 i18n message로 표시한다.
- 회원가입의 언어 선택은 `/api/auth/register`의 `locale`로 저장한다.
- 별도 provider 선택 UI는 사용하지 않는다.

**본문 상단 액션 바**

콘텐츠 상세 본문 영역 상단에 액션이 노출된다:

```
┌───────────────────────────────────────────────────────────┐
│ [상태: ready] [재처리] [💬 AI에게 질문] [🔗 공유] [📤 Export] [↗ 원본] │
└───────────────────────────────────────────────────────────┘
```

- **상태 표시**: `queued/fetching/extracting/ai_processing/indexing/ready/needs_review/failed`를 header와 activity에 표시한다.
- **재처리**: `failed` 또는 `needs_review` content는 `[재처리]` CTA를 제공한다. 재처리는 `/api/contents/{content_id}/reprocess`를 호출한다.
- **공유/내보내기**: member 이상은 public share 생성과 Markdown zip export를 시작할 수 있다. 공개 공유에는 raw extraction 원문을 기본 노출하지 않는다.
- **영구 삭제**: owner/admin은 soft delete된 content에서만 `[영구 삭제]` CTA를 볼 수 있다. 이 CTA는 `/api/contents/{content_id}/purge`를 호출해 asset purge job을 생성한다.
- **Citation**: summary, key points, chat answer에는 content id, source location, quote snippet을 연결한다.
- **Activity**: capture 상태 변경, 재처리, 공유, export, 삭제 이벤트는 `GET /api/contents/{content_id}/activity`로 별도 조회한다.

### 4.10 수집처 추가 - 계층형 (AC-02)

**목적:** 사용자가 출처(`CollectionSource`)를 등록 → 주기마다 자동 수집되어 라이브러리에 합류

처음에는 **주소 입력칸 하나**만 보인다. 주소를 붙여넣으면 시스템이 종류(`source_type`: `rss`, `sitemap`, `site`, `arxiv`, `github`, `huggingface`)를 자동 감지해 결과 배지를 표시하고 합리적인 기본값(전체 본문)을 적용한다. `[옵션 펼치기 ▼]`로 핵심 옵션을, `[고급 레시피]`는 링크로만 접근한다. AI 프리셋/일괄 등록 기능은 현재 출시 범위에 포함하지 않는다.

> 화면 라벨은 사용자 친화적으로 표시하되 API 값은 표준 enum을 사용한다. 예: `site` → "일반 웹사이트", `huggingface` → "Hugging Face 모델/카드". Hugging Face 수집처는 model card, README, paper link, dataset/model metadata 같은 설명 페이지와 메타데이터를 수집하며, repository 내부 source code 파일 전체 crawl은 기본 동작이 아니다.

붙여넣기 직후에는 `POST /api/sources/inspect`를 호출한다. 이 API는 source를 저장하지 않고 `source_type`, `display_label`, 기본 `config`, sample item preview를 반환한다. 사용자가 `[저장하기]`를 누를 때만 `POST /api/sources`로 실제 수집처를 생성한다.

```
│  │  include [/ai/*] [/papers/*]  exclude [/ads]│  │
│  └─────────────────────────────────────────────┘  │
│                                                   │
│  ─────────────── 미리보기 ───────────────         │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────┐  │
│  │ 시범 수집 1   │ │ 시범 수집 2   │ │ 시범 3   │  │
│  └──────────────┘ └──────────────┘ └──────────┘  │
│                                                   │
│                  [취소]      [저장하기]           │
└───────────────────────────────────────────────────┘
```

- **본문 범위**: 전체 본문(`extract_scope: full`, 기본값) / 요약만(`summary`) / 특정 영역(`region`, 고급).
- **수집 주기**: `schedule_interval`(hourly / daily / custom). 과도한 주기를 막는 최소 간격 가이드가 적용된다.
- **필터 규칙**: `config.include_rules`, `config.exclude_rules` — path/query/tag-like 문자열 규칙으로 source item 후보를 제한한다.
- **고급 레시피**: 까다로운 사이트용 세밀한 규칙. 일반 사용자는 거의 쓰지 않아 링크로만 접근.
- **미리보기**: `POST /api/sources/inspect`가 반환한 최근 항목 1~3개 카드로 제대로 들어오는지 확인한다.
- 종류를 못 알아보면 "일반 웹사이트"(`site`)로 처리하고, 접근이 안 되면 안내 메시지를 보여준다.

- **Source health**: failing/paused/needs_credential source를 redacted error와 함께 표시한다.
- **Jobs**: `job_runs` 기반 queue, stale heartbeat, failed retry action을 제공한다.
- **Models/Cost**: provider health, token/cost estimate, embedding dimension mismatch alert를 표시한다.
- **Audit**: login, role, credential, share, delete 등 security-sensitive event를 표시한다.
- **Storage**: object usage, purge job, export zip retention을 표시한다.
- **Users**: `super_admin`만 `GET /api/admin/users`로 email/name/locale/lock/delete status와 membership count를 조회한다.
- workspace `owner/admin`은 선택한 workspace의 cost estimate와 redacted job/source/audit만 본다.
- `super_admin`만 instance-wide model health, provider 전체 비용, system credential metadata, global storage, user metadata search를 본다. Admin Users는 impersonation, password reset, 사용자 content/raw extraction 조회를 제공하지 않는다.

### 4.15 수집 화면 (CAP-01)

**목적:** URL, YouTube URL, 직접 텍스트, 단일 PDF/Image를 저장하고 background processing 상태를 확인한다.

**접근 방법**

- 헤더의 `[+ 수집]` 버튼 클릭
- `/capture` 직접 진입
- 단축키 `Cmd/Ctrl + N`

- YouTube transcript가 없지만 metadata가 있으면 `needs_review`와 `youtube_transcript_unavailable`을 표시한다.
- metadata 확보 실패나 policy block은 `failed`로 표시하고 `[재시도]` CTA를 제공한다.

### 4.16 브라우저 확장 popup (EXT-01)

**목적:** 현재 탭 URL 또는 선택 텍스트를 빠르게 저장하고 처리 상태를 확인

현재 출시 범위의 확장은 현재 탭 저장과 선택 텍스트 저장만 제공한다. 파일 업로드, full-page HTML capture, 수집처 등록, 공개 공유 생성은 web app에서 처리한다.

**연결 전**

```
┌───────────────────────────────┐
│ 🍪 InfoSnack                  │
│                               │
│ 연결된 계정이 없습니다.        │
│                               │
│        [InfoSnack에 연결]     │
└───────────────────────────────┘
```

**연결 후**

```
┌───────────────────────────────┐
│ 🍪 InfoSnack           [설정] │
│                               │
│ 저장 대상                     │
│ (●) 현재 탭 URL               │
│ ( ) 선택 텍스트               │
│                               │
│ 제목                          │
│ ┌─────────────────────────┐  │
│ │ 현재 페이지 제목         │  │
│ └─────────────────────────┘  │
│ 메모                          │
│ ┌─────────────────────────┐  │
│ │                         │  │
│ └─────────────────────────┘  │
│ 태그 [#RAG] [+]              │
│                               │
│                  [저장]      │
└───────────────────────────────┘
```

**저장 상태**

```
┌───────────────────────────────┐
│ 저장됨                         │
│ queued → extracting            │
│                               │
│        [상세 열기] [다시 저장] │
└───────────────────────────────┘
```

- 연결은 web app에서 `POST /api/extension/auth/codes`로 one-time code를 만들고, popup이 `POST /api/extension/auth/exchange`로 token을 받는다.
- 현재 탭 URL 저장은 `/api/captures/url`, 선택 텍스트 저장은 `/api/captures/text`를 사용한다.
- 확장 token scope는 `capture:create`, `content:read:minimal`만 허용한다.
- popup 상태는 `disconnected`, `connected`, `saving`, `saved`, `failed`를 사용한다.
- 저장 실패 시 redacted error message와 `[다시 시도]` CTA를 표시한다.
